# Phân Tích Và Xây Dựng Cấu Trúc Website Template

## Phân tích cấu trúc giao diện
- **Header:** Nằm ở vị trí trên cùng, hiển thị thương hiệu và tiêu đề chính của trang web.
- **Navigation:** Thanh điều hướng gồm 4 liên kết chính giúp chuyển đổi giữa các trang (Trang chủ, Giới thiệu, Dịch vụ, Liên hệ).
- **Content Section:** Bố cục dạng 2 cột kết hợp Flexbox, gồm phần nội dung văn bản bên trái và hình ảnh minh họa bên phải.
- **Footer:** Đặt ở cuối trang, chứa thông tin bản quyền của website.
